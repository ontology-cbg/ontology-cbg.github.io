.. _installation:

============
Installation
============

---------------------
Software requirements
---------------------

^^^^^^^^^^^
All systems
^^^^^^^^^^^

* 12+ GB RAM, more for larger runs


^^^^^
macOS
^^^^^

* macOS 26.6.2 (or above)


^^^^^^^
Windows
^^^^^^^

* Windows 11 
* x64-based processor

^^^^^
Linux
^^^^^

* Ubuntu 24.04 (Ubuntu 26.04 coming soon)
* glibc 2.39 

**Note for all:** We cannot guarantee optimal ONTOLOGY performance if run using earlier versions of each operating system.

------------
Installation
------------

^^^^^
macOS
^^^^^

* Double-click .dmg file
* Drag ONTOLOGY app icon to Applications

^^^^^^^
Windows
^^^^^^^

* Double-click the Ontology_<>.exe file. 
* Walk through the install steps
* If a warning from Windows pops up, click 'More Info', then click 'Run Anyway'.

^^^^^
Linux
^^^^^

Please run the following from the directory holding the .deb file:

sudo apt install ./Ontology_<VERSION_NUMBER>_amd64.deb

Uninstall:
sudo apt remove ontology
