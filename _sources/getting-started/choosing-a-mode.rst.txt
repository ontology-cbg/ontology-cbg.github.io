.. _ABOUT_DIFFERENT_MODES: 

===============
Choosing a mode
===============

-----------------------------
DNA Barcoding - Standard mode
-----------------------------

Standard mode should be used for first-time users with ONTOLOGY kits through the entire workflow. Standard mode supports multiple 96-well PCR plates and guides users through sample preparation (including specimen images) and metadata upload for each plate, one plate at a time. 

Standard mode is the default mode used after selecting the **DNA Barcoding** workflow. 

-----------------------------
DNA Barcoding - Advanced mode
-----------------------------

Advanced mode enables experienced users with ONTOLOGY kits to complete the workflow as quickly as possible and is initiated once sequencing has completed. Rather than guiding users through sample preparation in a "plate-by-plate" fashion, Advanced mode handles speciment preparation and metadata for all plates at one time.

To switch to "Advanced mode", toggle the **Switch to Advanced Mode** button on the right sidebar, ideally before/during the initial 'Prepare' stage.

---------------------------
DNA Barcoding - Custom mode
---------------------------

Custom mode provides a flexible **DNA Barcoding** workflow for users who are not using ONTOLOGY kits. Samples, images, and metadata are prepared and provided by the users, and ONTOLOGY guides input file structure and provides only a general reference guide for preparing DNA sample ("Implementation" stage).

To switch to "Custom mode", first (1) enter Advanced Mode by toggling the **Switch to Advanced Mode** button on the right sidebar. Then, (2) toggle custom mode by pressing the ONTOLOGY logo (double helix) button on the Prepare screen (i.e., **Advanced User Run - ONTOLOGY kit** screen).

------------------------
Metabarcoding - Kit mode
------------------------

Kit mode is intended for users with ONTOLOGY kits and is similar to the **DNA Barcoding** workflow's "Advanced mode". Users may prepare and submit metadata for a batch of 96-well PCR plates at once. Note that a "plate-by-plate" mode is not available for **Metabarcoding** in ONTOLOGY.

Kit mode is the default mode for the **Metabarcoding** workflow of ONTOLOGY.

---------------------------
Metabarcoding - Custom mode
---------------------------

Custom mode provides an interface and workflow for **Metabarcoding** without using ONTOLOGY kits. Metadata and mapping file templates are provided to the user, which may be filled out and uploaded by the user.

To switch to "Custom mode", toggle custom mode by pressing the ONTOLOGY logo (double helix) button on the Prepare screen (i.e., **Launch Run - ONTOLOGY kit** screen).
