=========
Implement
=========

The **IMPLEMENT** workflow is largely performed in the molecular laboratory and the software is not highly-interactive. In this section of the manual, you can find the protocols used during **IMPLEMENT**.

.. _implement_protocols:

PROTOCOLS
---------

Each protocol is available as a downloadable PDF, listed in the order they are
performed in the laboratory.

* :download:`Specimen handling </protocols/specimen_handling.pdf>`
* :download:`Tissue sampling </protocols/tissue_sampling.pdf>`
* :download:`DNA extraction (alkaline lysis) </protocols/dna_extraction_alkaline_lysis.pdf>`
* :download:`PCR </protocols/pcr.pdf>`
* :download:`Agarose gel check </protocols/agarose_gel_check.pdf>`
* :download:`PCR pooling </protocols/pcr_pooling.pdf>`
* :download:`Library preparation </protocols/library_preparation.pdf>`
* :download:`Flow cell loading </protocols/flow_cell_loading.pdf>`
