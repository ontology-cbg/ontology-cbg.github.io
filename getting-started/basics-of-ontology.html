Basics of ONTOLOGY

ONTOLOGY is an end-to-end platform for DNA Barcoding and Metabarcoding workflows, which include sample preparation, processing, and bioinformatic analysis.

ONTOLOGY kits come as batches—a set of plates with a unique six-digit alpha-numeric code recognized by the software. Each plate in the batch has a batch code and the unique plate ID (from 1 to 24) printed on it.

ONTOLOGY is designed around the analysis of multiplexed samples pooled into a single run of a sequencer. Thus, the unit of analysis in ONTOLOGY is the run.

ONTOLOGY workflows are divided into three phases:

  • PREPARE: Initiate run; upload metadata and images (images for DNA Barcoding only)

  • IMPLEMENT: Complete molecular laboratory tasks

  • ANALYZE: Analyze sequence data using DNA Barcoding or Metabarcoding workflows; view run summary; For DNA Barcoding - upload barcode sequences and images to repository (BOLD)

If you want to use our example dataset, you should then have a look at the Tutorial section, which provides instructions on how to download this data.
