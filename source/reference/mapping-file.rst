============
Mapping file
============

.. container:: file-guide

    **Plate ID**
        Indicate plate name or number (e.g, 6)

    **Well ID**
        Indicate well number (e.g., B09)

    **Sample ID**
        Indicate sample name corresponding to well (e.g., GMP-58226). Replicate number (**Metabarcoding** Workflow only) should be indicated in the "Replicate" Column.

    **Forward UMI / Reverse UMI**
        Provide sequence

    **Fw Primer Sequence  / Rv Primer Sequence**
        Provide sequence

    **Primer Set Name**
        Standard or memorable name for primer set (will be saved)

    
    *Metabarcoding workflow only*:

    **Replicate**
        Replicate number for the sample (e.g., 2)

    **Negative Control**
        Indicate negative controls using "1", otherwise use "0" for all other values.

    **Positive Control**
        Placeholder for future implementation of positive control. For now, enter 0 for all values.

    **Custom ID**
        Unique string to give to well/row.
